# 더조커 홍대점 · 머더미스터리 찾기

구글 스프레드시트를 데이터 원본으로 쓰는 정적 웹사이트입니다. GitHub Pages로 무료 호스팅하고,
시트를 수정하면 사이트도 새로고침 시 자동으로 반영됩니다.

---

## 1. 처음 세팅 (새 계정 기준)

### A. 구글 시트
1. 새 스프레드시트를 만들고, 같이 제공된 `새시트_가져오기용.csv`를 **파일 → 가져오기 → 업로드**로 불러옵니다.
   (옵션은 "현재 시트 바꾸기", 구분자 "쉼표")
2. 1행 헤더가 이렇게 되어 있는지 확인: `이름 | 인원 | 알바생 코멘트 | 사진 링크 | 플레이 타임 (분)`
3. **공유 설정**: 오른쪽 위 초록색 "공유" → 일반 액세스를 **"제한됨"**으로 두고, 같이 관리할 분들만 이메일로 "편집자" 추가
4. **파일 → 공유 → 웹에 게시** → 형식을 **쉼표로 구분된 값(.csv)** 으로 선택 → 게시 → 생성된 링크 복사
   (이 링크는 읽기 전용이라 공유 설정과 별개로 사이트에서 읽을 수 있습니다)

### B. 코드에 시트 링크 넣기
`script.js` 맨 위의 이 줄에서 따옴표 안을 복사한 링크로 교체합니다.
```js
const SHEET_CSV_URL = "PASTE_YOUR_PUBLISHED_CSV_LINK_HERE";
```
(링크를 넣기 전에는 같은 폴더의 `data.csv`로 미리보기가 동작합니다. `index.html`을 더블클릭해 확인해보세요.)

### C. GitHub 업로드
1. 새 저장소(Public) 생성 → **Add file → Upload files**
2. 이 폴더 **안의 내용물**(`index.html`, `style.css`, `script.js`, `data.csv`, `README.md`, `assets` 폴더)을 올립니다.
   폴더 자체를 올리면 `index.html`이 한 겹 안쪽으로 들어가 사이트가 안 열립니다.
3. **Settings → Pages** → Branch를 `main` / `/ (root)`로 두고 Save
4. 몇 분 뒤 `https://[아이디].github.io/[저장소이름]/` 주소로 사이트가 열립니다.

### D. 사진 폴더 (구글 드라이브)
- 운영하는 계정(사장님)의 드라이브에 사진 폴더를 만들고, 같이 올릴 분들을 편집자로 초대합니다.
- 사진 파일은 **"링크가 있는 모든 사용자 - 뷰어"** 로 공유해야 사이트에서 보입니다.

---

## 2. 시트 입력 규칙

| 열 | 내용 | 예시 |
|---|---|---|
| 이름 | 작품 이름 | `살인 라이브` |
| 인원 | 숫자 또는 범위 | `5`, `4~5` |
| 알바생 코멘트 | `별점 / 5 \| 코멘트` (별점만 써도 됨) | `4.5 / 5 \| 초보자 추천` |
| 사진 링크 | 드라이브 공유 링크를 그대로 붙여넣기 | `https://drive.google.com/file/d/ID/view?usp=drive_link` |
| 플레이 타임 (분) | **분 단위 정수** | `90`, `150` |

- 열 이름은 "이름/인원/코멘트/사진/플레이타임" 같은 단어가 들어 있으면 자동 인식됩니다. 열 순서는 상관없습니다.
- "테마" 열을 추가하면 테마 필터가 자동으로 나타납니다.

## 3. 사이트 동작

- 인원수 최소값 기준 오름차순으로 **항상 자동 정렬**됩니다 (시트에 어디에 추가하든 무관).
- 플레이타임 필터는 60~300분 범위이며, "⏱ 플레이타임으로도 찾기" 버튼을 눌러야 열립니다.
  이 필터를 켜면 플레이타임을 아직 입력하지 않은 작품은 제외됩니다.
- 사진 썸네일을 누르면 크게 볼 수 있습니다.
- 사진이 없거나 링크가 잘못됐으면 "?" 자리표시자가 표시됩니다.

## 4. 사진이 안 뜰 때

1. 해당 파일이 "링크가 있는 모든 사용자"로 공유되어 있는지 확인
2. 링크가 `https://drive.google.com/file/d/…/view…` 형태인지 확인
3. 시트 수정 직후라면 몇 분 뒤 새로고침

## 5. QR 코드

사이트 주소가 확정되면 그 주소로 QR 코드를 만들어 매장에 붙입니다.
